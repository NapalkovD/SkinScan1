# SkinScan

Android-приложение (Kotlin + Jetpack Compose): фото кожи -> предварительный анализ нейросетью (Qwen-VL).

1. Откройте папку проекта в Android Studio (File > Open).
2. В файл local.properties добавьте строки из local.properties.example (AI_BASE_URL, AI_MODEL, AI_API_KEY).
3. Дождитесь Gradle Sync и запустите (Run).
